# Variant A — Moonlit Idol homepage mockup

作成先: `/opt/data/Tatekenmes/sketches/001-moonlit-idol/`

## 概要

VTuber 公式サイトのリデザイン案として、**明るくプレミアムな印象**を軸にした Variant A の静的モックアップを作成しました。既存サイトにある静かな夜気配を完全には消さず、背景の青み・薄い影・グラデーションの沈みで「ほんのりダークな下地」を残しています。

## ねらい

- キャラクターを最初に強く見せるヒーロー構成
- 丸いナビゲーションピルによる“公式感”のある導線
- airy layout / 余白多め / ガラス風カード / つや感のある面構成
- `Diary / Profile / Worldview` をトップ内で一覧できる一枚構成
- ニュース風・告知風のフェイク情報ブロックは入れない
- すべて日本語UIコピーで統一

## 実装内容

### `index.html`

単一ファイル完結の HTML モックアップです。

- 外部依存なし
- CSS / JS をファイル内に同梱
- ヒーロー右側に抽象的なキャラクタービジュアルを CSS だけで表現
- Diary セクションに最小限のタブフィルターを実装
- hover state と軽い浮き上がり演出あり
- レスポンシブ対応あり

### デザインの特徴

- 明度高めの背景に、青紫・アクア・ピンクのアクセントを配置
- 大きな角丸と半透明レイヤーで glossy / premium な質感を付与
- 下方向にわずかな暗色グラデーションを混ぜ、夜の余韻を維持
- 情報量を盛りすぎず、公式トップとして回遊の気持ちよさを優先

## 補足

このモックアップは **静的なスケッチ** です。実サイト実装用のフレームワークやビルド設定には依存していません。実運用へ落とし込む際は、ここで定義した情報階層・配色・カードスタイルを Next.js 側へ移植する前提です.
